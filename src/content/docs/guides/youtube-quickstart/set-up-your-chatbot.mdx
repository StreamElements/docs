## Add the bot as a moderator

:::note[Before you start]
Your stream must be **public** and **live** — the bot can't join a private, unlisted, or offline stream.
:::

<Steps>

1. Open [YouTube Studio](https://studio.youtube.com/) and go to **Settings → Community**.
2. Under moderators, add either of these as a moderator:
   - `https://youtube.com/c/streamelements`
   - `https://www.youtube.com/channel/UCjerlCIbLPQwSnYlClkjDXg`
3. While live, view **Live chat** rather than **Top chat** — Top chat can hide the bot's messages.

</Steps>

**Bot didn't join?** Confirm your stream is public, that you're shown as live in the StreamElements dashboard, and that you added the correct channel above as a moderator.

:::note[A couple of things work differently on YouTube]
You can't change the bot's display name on YouTube. And since [Loyalty](/loyalty) isn't available for YouTube accounts, anything built on it — Giveaways, the Stream Store, Viewer Queue, Media Requests — won't work either. Commands, timers, and spam filters are unaffected.
:::

## Create your first command

![The Chat commands tab in the bot command dashboard, showing the built-in Default commands](/img/youtube-quickstart/chat-commands.jpg)

<Steps>

1. From the [bot command dashboard](https://streamelements.com/dashboard/bot/commands), open the **Custom commands** tab and click **Add new command**.
2. Name it — for example `!lastseen`.
3. Add a reply, using [variables](/chatbot/variables) like `$(user)`:

   ```streamelements
   $(user) was last seen $(user.lastseen) ago
   ```

4. Click **Activate command**.

</Steps>

![The Add new command modal](/img/youtube-quickstart/add-command-modal.jpg)

![The command form, with name, reply, and activation options](/img/youtube-quickstart/command-form.jpg)

## Set up your first timer

Timers post automated messages — social links, schedule reminders — at set intervals while you're live.

<Steps>

1. From the [bot timers dashboard](https://streamelements.com/dashboard/bot/timers), click **Add new timer**.
2. Name it, add a message, and set the **Online interval** in minutes.
3. Click **Activate Timer**.

</Steps>

![The Timers page before any timers have been created](/img/youtube-quickstart/timers.jpg)

![The Add a timer modal, with template options like Socials, Discord, and Hydration break](/img/youtube-quickstart/add-timer-modal.jpg)

## Turn on spam filters

Worth doing before your first real audience shows up. In the dashboard, go to **Chatbot → Spam filters** and pick a protection level — **Minimum**, **Medium**, or **Maximum** — as a starting point, then expand any individual filter (like [Banned Words](/chatbot/filters/bannedwords)) to fine-tune it.

![The Spam filters page, with individual protections and a custom protection level](/img/youtube-quickstart/spam-filters.jpg)

![The Banned words page, where you create phrase groups to filter chat](/img/youtube-quickstart/banned-words.jpg)

![The Create new group form, for setting up a banned-phrase group with its own timeout and exclusions](/img/youtube-quickstart/create-group-modal.jpg)
