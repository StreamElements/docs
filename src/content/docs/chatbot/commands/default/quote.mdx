The `!quote` command interacts with the channel's quote system. Viewers can use it to display a random saved quote. Moderators and the broadcaster can use subcommands to add new quotes or remove existing ones.

## Usage

**To display a random quote:**

```streamelements
!quote
```

**To display a specific quote by ID:**

```streamelements
!quote <quote_id>
```

The ID can also be prefixed with `#`, e.g. `!quote #42`.

**To add a quote (Moderator+):**

```streamelements
!quote add <quote_text>
```

**To remove a quote (Moderator+):**

```streamelements
!quote remove <quote_id>
```

:::caution[Permissions]
Adding (`add`) and removing (`remove`) quotes requires **Moderator** permission level or higher. Viewing quotes is available to everyone.
:::

:::note
Quotes cannot be **edited** from chat — only added and removed. To edit the text of an existing quote, use the StreamElements Dashboard.
:::

<ChatExample messages={[

]} />

## Parameters

*   `<quote_id>` (Optional): The specific ID number of the quote to display or remove, with or without a `#` prefix.
*   `add <quote_text>` (Moderator+): The subcommand `add` followed by the text of the quote to save.
*   `remove <quote_id>` (Moderator+): The subcommand `remove` followed by the ID of the quote to delete.

## Configuration

*   The permission levels for adding and removing quotes can be adjusted under `Chatbot` -> `Chat Commands` -> `Default Commands`.
*   Editing the text of existing quotes is only possible from the StreamElements Dashboard.

## Aliases

*   `!quote add`: `!quote +`
*   `!quote remove`: `!quote rem`, `!quote delete`, `!quote del`, `!quote -`
