The `!8ball` command simulates a magic 8-ball toy: ask it a question and it answers with a random verdict.

## Usage

To use the command, type `!8ball` followed by an optional question in the chat. The chatbot will respond with a random fortune-like answer.

```streamelements
!8ball [question]
```

The `[question]` part is entirely optional and does not influence the random outcome.

## Configuration

Enable the 8ball module under `Chatbot` -> `Modules`, where you can also customize the list of possible responses the command draws from.
