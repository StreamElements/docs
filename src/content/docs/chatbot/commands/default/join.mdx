The `!join` command allows viewers to enter an **active raffle** in the chat. Viewers use this command to participate in raffles started by moderators using either [`!sraffle`](/chatbot/commands/default/sraffle/) or [`!raffle`](/chatbot/commands/default/raffle/).

## Usage

To enter the currently active raffle, simply type:

```streamelements
!join
```

There are **no parameters** for this command.

## Configuration

*   The **Raffle module** must be enabled in your StreamElements dashboard (`Chatbot` -> `Modules` -> `Raffle`).

## Related Commands

*   [`!sraffle`](/chatbot/commands/default/sraffle/): Starts a standard, single-entry raffle.
*   [`!raffle`](/chatbot/commands/default/raffle/): Starts a points-based raffle where viewers spend points to enter (entry via `!ticket` or `!join`).
*   [`!cancelraffle`](/chatbot/commands/default/cancelraffle/): Cancels the active raffle.
