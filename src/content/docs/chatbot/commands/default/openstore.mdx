The `!openstore` command allows streamers and moderators to quickly re-enable all **regular** (non-sound effect) items in the StreamElements loyalty store that were previously disabled (e.g., using `!closestore`).

## Usage

To enable all regular store items, use the following command in chat:

```streamelements
!openstore
```

<ChatExample messages={[
  { persona: 'moderator', message: '!openstore' },

<ChatExample messages={[

## Configuration

*   The command's permission level can be adjusted under `Chatbot` -> `Chat Commands` -> `Default Commands`.

## Related Commands

*   [`!closestore`](/chatbot/commands/default/closestore): Disables all *regular* (non-SFX) items in the loyalty store.
*   [`!disablesfx`](/chatbot/commands/default/disablesfx): Disables only sound effect (SFX) items in the loyalty store.
*   [`!enablesfx`](/chatbot/commands/default/enablesfx): Enables only sound effect (SFX) items in the loyalty store.
*   [`!redeem`](/chatbot/commands/default/redeem): Allows viewers to redeem store items.
*   [`!items`](/chatbot/commands/default/items): Provides a link to the store page.
