The `!when` command allows viewers to check the status of **their own song request** in the media request queue. It provides the song's position in the queue and an estimated time until it plays. You can also pass a YouTube URL or video ID to check where a specific song sits in the queue.

## Usage

To check the status of your own song request:

```streamelements
!when
```

To check the queue position of a specific song:

```streamelements
!when <youtube_url_or_id>
```

## Configuration

*   Requires the **Media Request** module to be enabled.
*   Without an argument, the command checks the queue for a request made by the user issuing the command. With a YouTube URL or video ID, it looks up that song's position instead.
*   Default cooldown: 15 seconds global.
