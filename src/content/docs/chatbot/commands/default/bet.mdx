The `!bet` command allows viewers to use their loyalty points to bet on the outcome of a contest or event defined by the streamer. This command is used **while a bet is active**, which is initiated through the StreamElements Dashboard. Viewers can check the active contest with [`!contest`](/chatbot/commands/default/contest).

## Usage

To place a bet while a betting contest is open, viewers use the following syntax:

```streamelements
!bet <option> <points>
```

## Parameters

*   `<option>` (Required): The specific betting option the viewer wants to choose (defined by the streamer when starting the bet).
*   `<points>` (Required): The number of loyalty points to wager. This can be a specific number, a percentage (`50%`), or use `k` for thousands (`5k`), `m` for millions (`1m`). The amount must stay within the minimum and maximum bet configured for the contest.

## Configuration

*   Betting contests can only be **started from the StreamElements Dashboard** — there is no chat command to create one. Streamers define the options, duration, minimum/maximum bet, and other settings there.
*   Viewers need sufficient loyalty points to place a bet.

## Related Commands

*   [`!contest`](/chatbot/commands/default/contest): Checks the status and details of the currently active betting contest.
*   [`!points`](/chatbot/commands/default/points): Checks a user's current loyalty point balance.
