The `!volume` command allows moderators to check or adjust the volume level of the StreamElements media request player.

:::caution[Permissions]
By default, only users with **Moderator** permission level or higher can use this command.
:::

## Usage

**To check the current volume:**

```streamelements
!volume
```

**To set a new volume level:**

```streamelements
!volume <level>
```

## Parameters

*   `<level>` (Optional): A number between `0` and `100` representing the desired volume percentage. If omitted, the command displays the current volume.

## Configuration

*   Requires the **Media Request** module to be enabled.
*   The command's permission level can be adjusted under `Chatbot` -> `Chat Commands` -> `Default Commands`.

## Related Commands

*   [`!songrequest`](/chatbot/commands/default/songrequest/): Used to request songs or media content.
*   [`!skip`](/chatbot/commands/default/skip/): Skips the currently playing media request.
*   [`!play`](/chatbot/commands/default/play/) / [`!pause`](/chatbot/commands/default/pause/): Controls media playback.
