---
title: Overlay Editor Shortcuts
description: "Keyboard shortcuts for the StreamElements Overlay Editor: move, duplicate, group, and align widgets without leaving the keyboard."
---

| Key | Action |
|-----|--------|
| <kbd>Delete</kbd> | Delete selected widget |
| <kbd>Shift</kbd> + <kbd>D</kbd> | Duplicate selected widget |
| <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Move widget 1px |
| <kbd>Shift</kbd> + <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | Move widget 10px |
| <kbd>Esc</kbd> | Unselect widgets |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Z</kbd> | Undo last action |
| <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Y</kbd> | Redo last undo action |
| <kbd>Alt</kbd> + <kbd>X</kbd> | Reset zoom |
| <kbd>Alt</kbd> + <kbd>F</kbd> | Fit to screen |
| <kbd>Shift</kbd> + <kbd>G</kbd> | Group selected widgets |
| <kbd>Shift</kbd> + <kbd>U</kbd> | Ungroup selected widget group |
