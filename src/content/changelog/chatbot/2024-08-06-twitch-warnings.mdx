---
title: Twitch Warnings support
description: Spam filters and banned words now support Twitch Warnings, with a new dropdown for customizable moderation actions.
date: 2024-08-06
---

Added support for Twitch Warnings in spam filters and banned words.

A new dropdown menu lets you customize the moderation action taken:

- Warn and delete message
- Timeout user
- Ban user
- Delete message only
